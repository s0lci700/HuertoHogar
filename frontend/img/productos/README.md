# Imágenes de productos — placeholders

Estas 9 imágenes (`fr001.svg` … `pl001.svg`, una por cada código de `database/productos.json`) son **placeholders**, no fotos reales de producto. Cada una es un SVG generado que muestra el nombre y código del producto para que el catálogo se pueda renderizar y maquetar ahora.

Antes de la entrega de EV1, reemplazar cada archivo por una foto real del producto, manteniendo el mismo nombre base (ej. `fr001.svg` → `fr001.jpg`) y actualizando la extensión en el campo `imagen` de `database/productos.json`.
